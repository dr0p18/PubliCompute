# Contributing to PubliCompute

Contributions are welcome, especially bug reports from real hardware and real
home lines: the GPU model, the driver version, the line speed and the logs of
`publicompute status` help a lot.

* **Open an issue first** if your pull request adds a feature, so we can discuss
  it before you spend time on it. Bug fixes can go straight to a pull request.
* **Target the `dev` branch**, not `main`.
* **Follow the existing style**: simple code, comments that explain why and not
  what, no abstractions without a reason. Identifiers and comments are in
  English.
* **Keep pull requests small** and focused on one change, with the tests you ran.
* **License**: by contributing you agree that your work is released under the
  license of the files you change (Apache License 2.0, or MIT for the engine
  patches in `engine/patches`).
* **Security issues**: please do not open a public issue; write to
  info@publicompute.com instead.
