# Contributing to PubliCompute

Open an issue before proposing a feature. For a bug report, include the
operating system, GPU and driver if relevant, the version, and the steps to
reproduce it. Remove credentials and private data from any attached logs.

Send pull requests to `dev`. Keep changes focused and explain why they are
needed. Run the relevant tests. If you change the engine patches, rebuild the
pinned tree and follow the checks in [the engine guide](engine/README.md).

Contributions use the license of the files they change. The workspace uses
[Apache-2.0](LICENSE), and the [engine patches](engine/README.md) use MIT.
