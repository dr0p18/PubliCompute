# PubliCompute

A distributed network for AI inference. Lend your gaming GPU in its idle hours and use AI models that are too big to
run on your PC: your card pays for your subscription.

Large models run as a **chain**: one model split in stages across several GPUs in the same region.

Website: <https://publicompute.com>

## Status

Early beta. This repository hosts the release packages of the Linux agent and client. The source code of what runs on
your PC will be published here at launch.
